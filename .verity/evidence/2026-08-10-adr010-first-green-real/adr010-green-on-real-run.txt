WHAT EACH DECISION GETS FROM THIS

  D1  observed, not constructed. The fixtures assert the writer's reading of a
      shape; this asserts the whole path -- child, launcher, extracted writer,
      disk -- and the entry is byte-equal to the child's, not a reconstruction.
  D2  strengthened. The denial did NOT come from the PreToolUse hook: the
      guard's DENY list is sixteen Bash-command patterns and carries no
      tool-name and no path rule, so its only reach over Write is the HALT
      check, which was not engaged. This entry was produced by the allowlist
      layer -- a THIRD producer, beside the hook and the settings deny rule
      D2 names -- and its shape is the shape D2 assumed. The claim that the
      parent cannot attribute a denial to a layer holds a fortiori and now
      also with the shapes measured equal.
  D3  held under load. The refusal moved neither the exit code (0) nor
      stop_reason (gate-pass). The state :144-146 called strange -- a run
      obstructed whose criteria passed anyway -- is this artifact.

WHAT THIS DOES NOT PROVE

  - The ordering rule for refusals.tools is NOT exercised: one element cannot
    have a wrong order. It stays verified only by the fixture, over five fresh
    interpreters.
  - The justification written beside that rule -- that the receipt is hashed
    into the append-only chain -- is cited outside its measurement scope.
    Measured this turn: the enforced launcher does not name receipt_chain, and
    the worker repo holds no receipt-chain file. The rule is kept because
    sorting is correct and free; the justification is carried as an open item.
  - The third-layer finding is n=1 and rests on one tool (Write). A settings
    deny rule was not exercised at all; ADR-010's second "Not measured" bullet
    is narrowed, not closed.
  - Nothing here bears on OR-2: no arm of this run had the model self-decline.

ONE FINDING OUTSIDE ADR-010's SCOPE, RECORDED AND NOT ACTED ON

The spec declares tools [Read, Bash, Grep, Glob]. Write is absent, and the
allowlist refused it. The artifact was created anyway, by Bash, with the exact
declared content: the DENY list carries no output-redirection pattern, so a
spec that withholds Write while granting Bash withholds a shortcut and not a
capability. Two runs of this slice, 2026-08-10, both show it.

ADR-010 makes that legible for the first time -- refusals.count > 0 beside
contribution CONTRIBUTED is its signature -- and nothing rejects it. A signature
is not a gate. That is a separate decision and is not taken here.
